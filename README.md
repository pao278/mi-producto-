# NexoAid

Proyecto individual de Product Management para desarrollar, desde Problem Discovery, un producto
nuevo provisionalmente denominado NexoAid.

El caso estudia la gestión y entrega de asistencia monetaria o basada en valor en contextos
humanitarios. Se parte del problema y del contexto, sin asumir una solución tecnológica.
OMNIAID se utiliza exclusivamente como referencia de mercado y aprendizaje del sector,
no como producto que se copiará.

## Estado
Etapa: Problem Discovery. Todavía no hay problema validado, oportunidad definida ni solución seleccionada.

## Estructura
- `WORKFLOW.md` — reglas de trabajo, validación, trazabilidad y guardado.
- `product/` — artefactos validados del producto (empezando por `product/intake.md`).

## Cómo se trabaja
Cada paso sigue el flujo definido en `WORKFLOW.md`:
skill → borrador → revisión → validación explícita → guardado → siguiente skill.
